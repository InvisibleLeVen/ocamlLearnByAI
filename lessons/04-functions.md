## 1. 定义函数

```ocaml
let succ n = n + 1;;
```

- `succ` 是函数名；
- `n` 是参数；
- `n + 1` 是函数体，是一个表达式；
- 交互环境显示 `val succ : int -> int = <fun>`。

OCaml 没有 `return`：函数体的值就是函数的结果。

```ocaml
succ 4;;   (* - : int = 5 *)
```

## 2. 调用：函数名与参数用空格分隔

```ocaml
succ 4        (* 5 *)
succ (2 + 3)  (* 6 *)
```

括号只用于把整个参数表达式包起来，不是调用的语法要求。

函数应用优先级高于普通运算符：

```ocaml
succ 5 * 2      (* 等价于 (succ 5) * 2 = 6 * 2 = 12 *)
succ (5 * 2)    (* succ 10 = 11 *)
```

## 3. 函数类型

`succ : int -> int` 读作“接受 int，返回 int”。

多参数函数：

```ocaml
let plus x y = x + y;;
```

类型是 `int -> int -> int`，箭头右结合，即 `int -> (int -> int)`。

```ocaml
plus 3 4;;   (* - : int = 7 *)
```

## 4. 柯里化（currying）预览

`plus 3` 只给第一个参数，得到的是一个新函数：

```ocaml
plus 3;;        (* - : int -> int = <fun> *)
(plus 3) 4;;    (* - : int = 7 *)
```

所以 `plus 3 4` 也可以理解成 `(plus 3) 4`。OCaml 的函数天然支持这种“一次给一个参数”的调用方式。

## 5. 参数的作用域

参数只在函数体内可见：

```ocaml
let succ n = n + 1;;
n;;   (* 错误：Unbound value n *)
```

函数参数不是全局变量，函数调用结束后也不会留在顶层环境中。

## 6. 函数体是表达式

因为 if 是表达式，函数体可以直接用 if：

```ocaml
let abs x = if x >= 0 then x else -x;;
abs 5;;      (* 5 *)
abs (-3);;   (* 3 *)
```

注意负数作为参数时要加括号：`abs -3` 会被解析成 `abs - 3`（减法），所以写 `abs (-3)`。

## 7. 默认非递归

```ocaml
let fact n = if n = 0 then 1 else n * fact (n - 1);;
```

这样写会报 `Unbound value fact`：`let` 默认非递归，函数体里的 `fact` 看不到正在定义的自己。递归要用 `let rec`，后面再学。

## 8. 与 C++/Python 的区别

| 项目 | C++ / Python | OCaml |
| --- | --- | --- |
| 返回值 | `return` | 函数体的值就是返回值 |
| 调用 | `f(x)` | `f x`，空格分隔 |
| 参数类型 | 通常显式声明 | 多数由类型推断 |
| 函数 | 不是普通值（C++ 函数指针除外） | 函数是普通值 |
| 多参数 | 一次传完 | 可一次给一个，柯里化 |

## 9. 本课要点

1. `let f x = e` 定义函数，`f 5` 调用。
2. 函数类型用箭头表示：`int -> int`。
3. 函数应用优先级高，复合参数要加括号。
4. 多参数函数可部分应用，即柯里化。
5. 参数只在函数体内可见；函数体是表达式，不需要 `return`。
