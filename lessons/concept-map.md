## 3. 核对结论（2026-11-19 对照 Fall 2026 官网目录）

- 教材**没有** CPS 章节，**没有** GADT 章节，**没有** effect handlers 章节；
- first-class modules 只在 5.9 函子一章的测试示例里出现过，不是独立主题；
- monad 只在 7.8；promise 在 7.2–7.4、7.7；ref 在 6.1；
- 管道（pipelining）在 4.6，属于第 4 章，之前漏排，已补进第 18 课；
- 官网目录含 8.2 Function Documentation 与 8.3 Module Documentation；本地第 15 课只覆盖规格，漏了文档写法及实现层的抽象函数/表示不变式，已补进第 18C 课；
- 第 5.1 Module Systems 与第 1 章的函数式编程视角此前未单独列入课程，前者已在模块课零散涉及、后者已在多处实践，安排于第 18A/18B 课做系统回顾；第 5.6 函数式数据结构併入第 26 课；
- 惰性求值与流在 **9.4（Sequences）**，`Lazy` 模块的记忆化在 9.5 → 第 **28** 课；
- 四项“教材没有”的专题选修已排入课程表：first-class modules、CPS、GADT、effect handlers（第 33、34、36、37 课）；Applicative 作为第 7.8 monad 单元的桥接内容；
- Curry–Howard **不是**教材缺失内容：它在 adv 目录有专章，含习题与官方解答，已从“附录（可选）”提升为**第 35 课**，排在 GADT 前。
