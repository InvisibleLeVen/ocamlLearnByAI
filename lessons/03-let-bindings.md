## 1. let 是绑定，不是赋值

OCaml 没有“给已有变量重新赋值”的语句。`let` 把一个名字绑定到一个值：

```ocaml
let x = 3 in
x + 1
```

读法：先求值 `3`，在 `in` 后面的表达式中把 `x` 绑定为 `3`，再求值 `x + 1`。结果 `int = 4`。

`=` 在 OCaml 中是比较相等，不是赋值：

```ocaml
x = 3   (* bool，判断 x 是否等于 3 *)
```

## 2. 局部 let：`let x = e1 in e2`

- 先求值 `e1`，得到值 `v`；
- 在 `e2` 中把 `x` 绑定为 `v`；
- 整个表达式的类型和值来自 `e2`。

```ocaml
let x = 3 in x > 2
```

`x > 2` 是 bool，所以整个 let 表达式是 `bool = true`，不是 int。

作用域：`x` 只在 `in` 后面的 `e2` 中可见，出了这个范围就不可见。

```ocaml
let x = 3 in x + 1;;   (* int = 4 *)
x;;                    (* 错误：Unbound value x *)
```

## 3. 嵌套 let 与作用域

```ocaml
let x = 2 in
let y = x + 3 in
x * y
```

- `x = 2`
- `y = x + 3 = 5`（右侧能看到外层的 x）
- 结果 `x * y = 10`

`y` 只在最内层 let 的 body 中可见；整个表达式结束后，`x`、`y` 都不再绑定。

## 4. 遮蔽（shadowing）

```ocaml
let x = 2 in
let x = x * 3 in
x + 1
```

第二个 `let` 的右侧 `x * 3` 使用的是**外层**的 `x = 2`，得到 6；随后新的 `x = 6` 只在第二个 let 的 body 中可见。结果是 `7`。

这不是重新赋值，而是新建一个同名绑定遮住旧的。`let` 默认**非递归**，所以右侧的 `x` 不会指向正在定义的新 `x`，不会造成递归。

遮蔽只在新的作用域内有效：

```ocaml
let x = 1 in
(let x = 2 in x) + x
```

内层 `x = 2` 只在括号内有效，括号外仍是外层的 `x = 1`，所以结果是 `2 + 1 = 3`。

## 5. 顶层 let：`let x = e;;`

在交互环境中，不带 `in` 的 `let x = e;;` 是一条顶层定义：把 `x` 加入当前环境，后续输入可以使用它。

```ocaml
let a = 7;;
let a = a * 2;;
a;;
```

- 第一条：`a = 7`
- 第二条：右侧的 `a` 是旧的 7，新绑定 `a = 14`，旧的被遮蔽
- 第三条：`a = 14`

同样是**遮蔽**，不是修改旧值。顶层再定义同名 `let` 只是换了一个新绑定。

## 6. 两种 let 的区别

| 形式 | 例子 | 作用域 | 整个表达式的值 |
| --- | --- | --- | --- |
| 局部 let 表达式 | `let x = 3 in x + 1` | 只在 `in` 后面 | body 的值 |
| 顶层定义 | `let x = 3;;` | 后续输入/文件剩余部分 | 定义本身不产生可用的值 |

顶层 `let` 在交互环境会显示绑定，但它的作用和局部表达式不同。

## 7. 一个 if 与 let 的组合

```ocaml
let x = if 2 > 5 then 1 / 0 else 9 in
x * 2
```

条件为假，只求值 else 分支，`then` 里的 `1 / 0` 不会执行；`x = 9`，结果是 `int = 18`。

## 8. 本课要点

1. `let` 是绑定，不是赋值；OCaml 的值不可变。
2. `let x = e1 in e2` 的类型来自 `e2`。
3. `x` 的作用域是 `e2`；嵌套 let 的内层能看到外层。
4. 同名 `let` 是遮蔽；默认非递归，右侧看旧绑定。
5. 顶层 `let x = e;;` 把绑定加入环境；局部 `let ... in` 不会。
