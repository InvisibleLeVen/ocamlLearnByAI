## 先补上包含关系

R1 的 `2. +. 0.5` 正确，两个操作数都是 float，运行结果为 `2.5`。用户说明首次遗漏小数点是粗心，原始答案与订正都保留。

R2 的“true 是值”本身正确，但完整分类是：true 既是值，也是表达式。

**值是不需要继续计算的表达式。因此，所有值都是表达式，但表达式不一定是值。**

| 代码 | 是表达式 | 本身已经是值 | 求值结果 |
| --- | --- | --- | --- |
| `true` | 是 | 是 | `true` |
| `3 > 2` | 是 | 否，还要进行比较 | `true` |

它们都有 bool 类型、求值结果相同，但代码本身是否已经是值，是另一个问题。

## if 表达式

形式：

```ocaml
if condition then expression_a else expression_b
```

先求条件的值，再仅对选中的分支求值；该分支的结果也是整个 if 的结果。

```ocaml
if 4 > 2 then 3 else 7
```

运行结果：`- : int = 3`。

可以把 if 放进另一个表达式：

```ocaml
10 + (if 4 > 2 then 3 else 7)
```

运行结果：`- : int = 13`。

可以借助 C++ 的 `条件 ? a : b` 理解“选择并产生一个结果”这一作用；这里只类比取值方式，不套用 C++ 的类型转换规则。

## 本轮先掌握三条规则

1. 条件必须是 bool。
2. then 与 else 两个分支的类型必须一致，整个 if 也具有这个类型。
3. 类型检查会检查两个分支；运行时只对选中的分支求值。

本轮练习都使用完整的 then / else。省略 else 的情况留到学习 unit 时再讨论。
