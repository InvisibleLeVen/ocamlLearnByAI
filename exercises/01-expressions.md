```ocaml
(* A *) 9 / 4
(* B *) 9.0 /. 4.0
(* C *) 6 > 2
```

## E01-2 · 找出问题

下面的表达式能通过类型检查吗？说明原因，并将它改成计算这两个数之和的合法浮点表达式。

```ocaml
2 + 0.5
```

用户首次答案（原文）：

> 不能，因为( + )函数期望的值是int，2 +. 0.5。

老师反馈：不能通过类型检查的判断与原因正确；运算符改为 `+.` 的方向也正确。但 `2 +. 0.5` 仍然不能通过类型检查，左边的 `2` 是 `int`，`+.` 的两个参数都必须是 `float`。

实际运行时的主要诊断：

```text
Error: This expression has type "int" but an expression was expected of type
         "float"
```

错误指向左侧的 `2`。已提供提示，完整修正式留给用户在 E01-R1 中完成。

订正或重试：E01-R1 已提交并通过，见下方记录。
