## E04-1 · 函数类型与参数作用域

```ocaml
let inc x = x + 1;;
inc 5;;
```

`inc` 的类型是什么？`inc 5` 的类型和值是什么？`x` 在 `let` 结束后还能用吗？说明理由。

用户答案：函数类型是 int -> int,inc 5的类型是int，值是6，x在let结束后不能用了，参数的作用域只限于在函数体内

老师反馈：正确。`inc : int -> int`；`inc 5 : int = 6`；`x` 是参数，只在函数体内可见，函数定义结束后不再绑定。判定：通过。

## E04-2 · 多参数与柯里化

```ocaml
let add x y = x + y;;
add 2 3;;
add 2;;
```

`add` 的类型是什么？`add 2 3` 的值是什么？`add 2` 得到什么？`(add 2) 3` 呢？说明理由。

用户答案：int -> int -> int，5, 得到一个类型是int -> int 的函数， (add 2) 3 得到一个值，add 2 返回一个int -> int 的函数然后apply 3这个参数，得到5.

老师反馈：正确。`add : int -> int -> int`；`add 2 3 = 5`；`add 2 : int -> int`；`(add 2) 3 = 5`，这正是柯里化：部分应用得到新函数，再应用到下一个参数。判定：通过。

## E04-3 · 调用优先级与括号

```ocaml
let inc x = x + 1;;
inc 2 * 3;;
inc (2 * 3);;
```

两个结果分别是什么？为什么不同？说明理由。

用户答案：inc 2 * 3 是9， inc (2 * 3)是7，因为优先级，函数apply的优先级大于运算符的优先级，

老师反馈：正确。`inc 2 * 3` 解析为 `(inc 2) * 3 = 3 * 3 = 9`；`inc (2 * 3) = inc 6 = 7`；函数应用优先级高于 `*`。判定：通过。
