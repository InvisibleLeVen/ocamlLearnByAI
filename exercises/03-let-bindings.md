## E03-1 · 嵌套 let 与作用域

```ocaml
let x = 3 in
let y = x * 2 in
x + y
```

整个表达式的类型和值是什么？`y` 在这个表达式结束后还能用吗？`x` 在 `let y = x * 2` 的右侧可见吗？说明理由。

用户答案：类型是int，值是9，y在这个表达式结束后用不了了，x在let y = x * 2的右侧是可见的，在let x = 3 in (作用域)，在作用域范围x都是可见的

老师反馈：正确。`x = 3`、`y = 6`，所以 `x + y = 9`；整个表达式类型为 int。`x` 的作用域覆盖 `let y = ...` 的右侧和 body；`y` 只在最内层 let 的 body 中可见，整个表达式结束后不再绑定。判定：通过。

## E03-2 · 遮蔽与非递归

```ocaml
let x = 5 in
let x = x + 1 in
x * 2
```

结果是什么？第二个 `let` 右侧的 `x` 指哪一个绑定？这会造成递归吗？说明理由。

用户答案：结果是12，与5绑定，因为新的x还没绑定，现在的x还是旧的绑定，不会造成递归，因为绑定的是旧的x，并不会产生递归

老师反馈：正确。第二个 `let` 右侧的 `x` 指向外层 `x = 5`，新绑定 `x = 6` 只在 body 中生效，所以 `6 * 2 = 12`。`let` 默认非递归，右侧不会引用正在定义的新绑定，因此不产生递归。判定：通过。

## E03-3 · 顶层绑定与局部绑定

```ocaml
let a = 10;;
let a = a + 5;;
a;;
```

依次输出什么？第二个 `let` 是重新赋值还是新绑定？接着输入：

```ocaml
let b = 1 in b + 1;;
b;;
```

会发生什么？说明理由。

用户答案：输出15，第二个let是新绑定，会输出2

补答：1.a的值是10，2 最后单独输入b;;解释器会报错，因为let b = 1 in b + 1是一个表达式，b的绑定只在in的作用域内是有效的，b不在顶层环境里了。

老师反馈：补答正确。第一条 `let a = 10;;` 中 a 的值是 10；`b;;` 会报 `Unbound value b`，因为局部 `let ... in` 的绑定只在 body 内有效，不进入顶层环境。结合原答，E03-3 的知识点已补齐。判定：通过（首答漏两点，补答后完整）。

## E03-4 · 复习：if 的分支求值

```ocaml
let x = if 3 > 2 then 42 else 1 / 0 in
x + 1
```

类型和值是什么？`1 / 0` 会被求值吗？为什么？

用户答案：类型是int，值是43， 1 / 0 不会被解释器求值，因为解释器求值过程判断条件是true之后就去求值then分支，不会走到else分支，

老师反馈：正确。条件 `3 > 2` 为 true，只求值 then 分支，`x = 42`，所以 `x + 1 = 43`，类型 int；else 中的 `1 / 0` 不执行。判定：通过。
